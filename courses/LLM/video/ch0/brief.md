# 大语言模型 · 第 0 章导读 · 视频简报（v2）

> 这一版的目标不是「把正文念一遍」，而是**让每个概念都有一张自己的图**。
> 参照物：`cc-default-workspace/remotion/llm-ch0-bili`。差距分析与本版做法见
> `video/visual-gap.md`。

## 学习者

- 起点：完全没接触过大模型；不假设会微积分、线代或机器学习。
- 已有知识：会算简单概率，看得懂初中数学符号；每天愿意花 30 分钟。
- 学完能做到：用自己的话解释 LLM 在做什么；说清后面 16 章各自回答什么问题；
  判断一条新闻标题是在陈述事实，还是在夸大。

## 这一集必须讲

1. 一句话定义：用海量文本训练、根据上文预测下一个词。
2. 一个可感知的例子：输入法联想 → 候选打分 → 接上一个词 → 继续猜。
3. 四个为什么：推理从哪来、规模为何突变、预测是否等于理解、为什么会胡说。
4. 一张图：一个目标 + 五个模块（表示、架构、数据、规模、对齐）。
5. 五个时代：1948–2002、2003–2016、2017–2019、2020–2022、2022–至今。
6. 一条反复出现的模式：手工部件 → 从数据学习的部件 → 规模推向质变。
7. 增量式写法：一次定义、每章写新增/前置、例子不复用。
8. 学习契约：耐心、笔、怀疑精神。
9. 跨领域对照：熵、梯度、MoE、预适应，并标出失效边界。

## 视觉要求（本版新增的硬指标）

| 要求 | 具体做法 |
|---|---|
| 每个分析概念至少一张专属图 | 22 个概念/场景各配图，全部用 image_generate 生成照片；离线时用无文字矢量图兜底 |
| 每场至少 2 个视觉节拍 | 一场内换图、换卡片、换图表，不做「一张卡片挂 40 秒」 |
| 不用等宽卡片糊满屏 | 主图 + 侧栏、时间轴 + 详情卡、节点图、三列对照等非对称版式 |
| 图表必须有轴名/单位/示意标注 | 规模曲线标 `规模 →` `能力 ↑` 与「示意图 · 非真实数据」 |
| 类比必须标失效边界 | 预适应卡底部写「进化没有目标函数，训练有明确损失」 |
| 图片来源可追溯 | `video/asset-credits.md` 逐张列出「生成 / 矢量绘制 / 归档」 |

## 明确不讲

- 不讲交叉熵、softmax、反向传播的公式推导（留给第 1、2 章）。
- 不讲训练细节、分布式系统、CUDA、具体产品评测。
- 不做参数规模排行榜，不预测未来时间点。

## 形式

| 项 | 目标 |
|---|---|
| 时长 | 6–7 分钟（硬上限 10 分钟） |
| 画幅 | 1920×1080，16:9，30 fps |
| 场景 | 9 个；每场 1–3 个视觉阶段 |
| 旁白 | 中文，一句一个意思；中文 ≤40 字，英文 ≤110 字符 |
| 字幕 | 中英双语烧录；另出 zh / en / bilingual 三份 SRT |
| 声音 | 中文配音；背景音乐 0.2 音量，人声优先 |
| 时间 | 只由真实 TTS 音频反推，不手改 timeline |

## 验收

1. 9 场都至少有一张专属图；四个「为什么」是四张不同的图。
2. 五个模块在图中各有自己的缩略图；五个时代各有自己的时代图。
3. 所有年份、论文、数字都能在 `research/source-ledger.md` 找到。
4. 每个场景抽 2 帧（阶段切换前后）无裁切、无重叠、字幕不挡内容。
5. `courseforge check` 通过；成片解码通过；三份 SRT 各 69 行。
