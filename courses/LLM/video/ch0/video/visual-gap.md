# 第 0 章视频：与 Claude 版的差距分析

参照：外部参考工程 `llm-ch0-bili`（本机路径，未随仓库分发；下称 **C 版**）。
被替换：本仓库旧版 ch0 视频（下称 **v1**）。
本版：**v2**，`courses/LLM/video/ch0`。

## 结论先行

C 版赢在**每场都在换视觉**：它把一章拆成 2–4 个视觉阶段，用图、卡片、时间轴、节点图、曲线轮流承担解释。
v1 输在**每场只有一张静态版式**：10 个场景、72 句，但每个场景从头到尾是同一组卡片或同一张照片；
观众在 20–40 秒里只得到一次视觉信息，剩下的时间都在读字幕。

v2 的目标不是「复刻 C 版」，而是把它最有效的三条做法拿过来，并修掉它自己也有的问题：
**多阶段、概念图、非对称构图**。

## 逐项差距

| 维度 | C 版 | v1 | v2 的做法 |
|---|---|---|---|
| 场景数 / 句数 | 9 场 / 60 句 | 10 场 / 72 句 | 9 场 / 69 句；场更少，但每场有 2–3 个阶段 |
| 视觉节拍 | 每场 2–4 个：定义→雨伞→候选→副产品；问题→结果；三个时代卡 | 每场 1 个：一组卡片挂 30–40 秒 | 每场 2–3 个阶段；例如 sentence 场：定义→雨伞→候选打分→规模/副产品 |
| 概念图 | 12 张照片 + 3 个手绘 glyph + 2 张图表 | 4 张照片，无概念图 | 22 张视觉，全部为 image_generate 生成照片（0 张矢量图） |
| 地图 | 节点图 + 连线 + 五词高亮 | 五张等宽卡片 | 节点图：预测→五个模块，每个节点有缩略图；五词卡片独立高亮 |
| 历史 | 时间轴 + 当前时代大卡 + 图片/glyph + 论文胶囊 | 时间轴 + 五张静态事件卡 | 时间轴 + 当前时代大卡 + 5 张时代图 + 论文胶囊 + 「大致边界」章 |
| 模式 | 三行「手工→数据」+ 规模曲线 + 羽毛预适应 | 静态左右对比表 | 三行换件 + 曲线 + 羽毛预适应 + 失效边界 |
| 方法 | 问题卡→规则卡（带 mini demo）→工作记忆条→三样东西 | 三张步骤卡 | 问题卡→三条规则（带账本/新增前置/例子 demo）→工作记忆六格 |
| 跨学科 | 三列图 + 链 + 失效边界章 | 一张羽毛图 + 三条 bullet | 四列图（热力学/生物学/经济学/预适应）+ 链 + 失效边界章 |
| 版式 | 800/1640 宽大卡、图片+文字、非对称 | 等宽卡片，底部常有大片空白 | 主图+侧栏、节点图、时间轴+大卡、四列图；不再用「一排等宽卡」承担所有场 |
| 字体 | 无衬线为主 | 无衬线为主 | 大标题改用宋体（Songti SC），正文/字幕用无衬线；更像「讲义」而不是「PPT」 |
| 转场 | 14 帧交叉淡化（**有素材透出风险**） | 8 帧淡到画布，章节卡不透明 | 保留 8 帧淡到画布；不做场景交叉淡化；场景内阶段才允许叠化 |
| 空屏 | 也有：f60 右半屏空、f355 下一章只占左半 | 多处：whys 下排空、map 右侧空、method 只有一张卡 | 所有网格改成同一时刻出现、整体高亮；右侧/下排不再留空 |
| 图片文字 | 图内无文字 | 图内无文字 | 图内无文字；所有标签/数字/轴名都在 HTML/SVG |
| 可核查 | 有来源账本 | 有 15 条来源账本 | 保留 15 条来源账本 + 图像类型/证据边界说明 |

## C 版值得学、但不照抄的点

1. **一场多阶段**：`sentence` 场把「定义 / 雨伞 / 候选 / 副产品」压进一场，减少章节卡次数。
2. **大卡 + 主图**：一张图占 600–800 px，文字只占一侧；v1 的照片太小、卡片太空。
3. **当前项高亮**：时间轴用 active 节点和大卡；规则/问题用 outline 表示「正在讲这个」。
4. **图内无文字**：所有词、数字、轴名都在 HTML/SVG 里；这让图片可复用、可翻译。
5. **一张图只解释一个概念**：四个 why 四张图，五个时代五张图，四个学科四张图。

## C 版的问题，v2 没有照抄

1. **场景交叉淡化**：C 版 `OVERLAP=14`，理论上上一场会透进下一场；v2 保持「8 帧淡到画布 + 不透明章节卡」。
2. **半屏空**：C 版 `f60` 右侧空、`f355` 只占左半；v2 把网格/公式卡改成同一时刻出现，避免半屏空。
3. **信息提前/滞后**：C 版有些数字/卡片比旁白早出现；v2 用 `cues()` 逐句对齐，文字和卡片只在对应句出现。
4. **时间轴按「年」排而非按「时代」排**：C 版节点间距等距，但年份跨度不等；v2 明确标「1948–2002 / 2003–2016 …」并注明「大致边界」。
