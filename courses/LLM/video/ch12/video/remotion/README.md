# courseforge Remotion template

A JSON-driven Remotion project. The agent writes narration + storyboard; the
template renders the video.

```
src/data/timeline.json     generated by `courseforge voice`
src/data/storyboard.json   copied from video/script/storyboard.json
src/Video.tsx              scene sequencing, header, chapter cards, subtitles
src/scenes/                cover / bullets / formula / curve / compare / steps / photo / timeline / outro
```

Read [STORYBOARD.md](STORYBOARD.md) for the schema.

## Commands

```bash
npm install
npx remotion studio
npx remotion render CourseVideo out/course.mp4 --crf=20
npx remotion still CourseThumbnail out/poster.jpg
```

`courseforge` wraps these commands and keeps paths consistent.
