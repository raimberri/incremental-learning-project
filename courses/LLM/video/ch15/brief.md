## 学习者

- 起点：看完第 0–14 章；知道 ReAct、RAG、上下文工程、RLVR 与评测的基本概念。
- 不假设：用过 MCP 或任何 agent 框架、读过 SWE-agent 论文、写过工具调用代码。
- 学完能做到：解释「模型」与「智能体」的差别在反馈回路；说清函数调用里谁请求、谁执行；
  区分短期、长期、程序性三层记忆；用 0.95 的 20 次方估算长任务成功率；判断一次
  「给 agent 加工具」是提升还是扩大攻击面。

## 这一集必须讲

1. 一个模型不是智能体：只输出 token，不改变世界；智能体要在环境里循环。
2. 循环四拍：观察、思考、行动，回到观察；OODA 与负反馈；停止条件是完成或预算耗尽。
3. 工具是模型的手：搜索、代码执行、数据库与接口、浏览器与电脑。
4. 函数调用四步：描述进上下文、模型发结构化请求、运行时执行、结果回填；参数校验与错误回填。
5. 关键分工：模型只请求，外部程序执行——这决定了整个安全模型。
6. 工具协议：2024 年 Anthropic 的 MCP 想统一接工具与数据源；标准降低的是适配成本。
7. 记忆：上下文之内与之外；短期、长期、程序性三层；写入、检索、清理。
8. 多智能体：可并行时有效；每次传话都是有损压缩，瓶颈是协议与共享状态。
9. 复合误差：0.95 的 20 次方约 0.36，100 次方约 0.006；对策是提可靠性、缩链条、加检查点。
10. 安全：间接提示注入、数据被当成指令、与 SQL 注入同构；最小权限、沙箱、人类确认、输出审查；只能限制爆炸半径。
11. 前沿快照：ReAct、MCP、SWE-agent、computer use、评测与对齐伪装；结论是快照，不是定论。
