# 大语言模型 · 第 2 章 梯度与反向传播 · 视频简报

> 这一章只做一件事：把「参数怎么自己变好」拆成两个可计算的动作——
> **沿着梯度下山**，以及**一次反向遍历算出所有梯度**。
> 课程正文见 [`../../curriculum/02-梯度与反向传播.md`](../../curriculum/02-梯度与反向传播.md)；
> 本文件只约定视频的范围与形式，不复制正文。

## 学习者

- 起点：看过第 1 章；知道损失、交叉熵、条件概率；会算简单偏导和链式法则。
- 不假设：写过 PyTorch、手推过矩阵反向传播、懂凸优化。
- 学完能做到：用自己的话解释梯度、学习率、mini-batch SGD、反向传播与残差连接；
  能手算 `ŷ = wx + b` 的两步梯度；能判断「再深一层就训不动」是工程问题还是数学问题。

## 这一集必须讲

1. 把训练想成在看不见的地形里下山：只有局部坡度，没有地图。
2. 梯度 = 偏导数向量，指向上升最快；更新规则 `θ ← θ − η∇L`。
3. 学习率的两个失败模式：太小走不动，太大跨过谷底；与欧拉法步长的同构。
4. 真实训练用 mini-batch 估计梯度（SGD）；噪声既是麻烦，也是探索工具。
5. 为什么不能逐参数做数值微分；反向传播 = 链式法则 + 动态规划。
6. 手算 `ŷ = wx + b`、`L = (ŷ − y)²`：损失 9、梯度 −18 / −6；`η=0.1` 过头，`η=0.02` 更近。
7. 同一算法的四个名字：反向传播 / 伴随法 / 4D-Var / 反向模式自动微分；影子价格。
8. 四个工程发明：Adam、Dropout、归一化、残差连接（谁最重要，为什么）。
9. 训练不是「写入知识」，而是在拟合分布；过拟合与正则化 = 奥卡姆剃刀的工程版。
10. 下一站：第 3 章表示学习。

## 视觉重点

- 损失曲面：一条 `L(θ)` 曲线 + 切线方向的下山箭头（示意函数，轴名与单位齐全）。
- 学习率：同一条抛物线上三组步点，小步 / 合适 / 发散，三色对照。
- SGD：完整数据 → 小批量抽样的网格，与平滑梯度 / 噪声梯度的路径对比。
- 反向传播：`x → h → ŷ → L` 节点图，前向与反向两遍走；旁注「一次前向的量级」。
- 残差：`h ← h + F(h)` 的方框图，梯度沿 `+` 直通。
