## 第 1 章　语言的概率论

**1. 词表 1000 个词，模型完全均匀乱猜，困惑度是多少？如果交叉熵是 3 nat，困惑度约是多少？**

均匀分布时 $q_i = 1/1000$，交叉熵 $H = -\sum p_i \log q_i = \log 1000 \approx 6.91$ nat，
困惑度 $= e^{6.91} = 1000$。这就是"困惑度 = 词表大小"的基准。
交叉熵 3 nat 时，$\mathrm{PPL} = e^3 \approx 20.1$，意思是"平均在 20 个词之间犹豫"。

**2. 为什么 n-gram 模型遇到"我养了一只穿山甲"会给整句话概率 0？神经语言模型为什么不会？**

n-gram 用计数估计概率。如果"我养了一只"后面跟"穿山甲"在语料里从未出现，
条件概率就是 0；链式法则连乘，整句概率为 0。
神经语言模型不直接数组合，而是用**词向量**做输入：它见过"我养了一只猫"，
而"猫"和"穿山甲"的向量因为上下文相似而接近，所以模型会给"穿山甲"一个非零概率。
本质区别：**前者记忆组合，后者学习关系**。

**3. 温度 $\tau = 0.1$ 和 $\tau = 2$ 分别适合什么场景？各有什么风险？**

- $\tau = 0.1$：分布接近 one-hot，输出几乎确定。适合事实问答、代码生成、需要可复现的场景。
  风险：重复、死板、陷入循环；同一个错误答案会被反复输出。
- $\tau = 2$：分布变平，冷门 token 也有机会。适合头脑风暴、创意写作。
  风险：不连贯、跑题、幻觉增加；低概率 token 被采到会破坏语义。

## 第 2 章　梯度与反向传播

**1. 学习率设为 10 会发生什么？设为 $10^{-8}$ 呢？**

$\eta=10$：步子太大，每步都跨过谷底，损失震荡甚至指数发散（梯度爆炸的极端形式）。
$\eta=10^{-8}$：每步几乎不动，训练慢到不可接受；在有限算力内根本没走到有意义的区域，
看起来像"模型不学习"。

**2. 反向传播为什么比"逐个参数做数值微分"快？快在利用了哪个性质？**

数值微分要对每个参数做一次"扰动 + 前向"，$N$ 个参数就是 $N$ 次前向，成本 $O(N)$。
反向传播利用**链式法则的复用**：上游传来的梯度 $\partial L/\partial h$ 被所有下游分支共享，
每个节点只做一次局部乘法。一次前向 + 一次反向，成本与一次前向同阶，就得到全部梯度。
这个"复用子问题结果"的性质，正是**动态规划**。

**3. 残差连接 $h_{l+1} = h_l + F(h_l)$ 中，如果 $F$ 恒为 0，网络会怎样？这说明残差的什么性质？**

网络变成恒等映射：输入原样传到输出。这说明残差块**很容易表示"什么都不做"**——
在标准多层网络里，让一层学出恒等映射反而很难（要精确学出 $W=I$）。
正因为"跳过"是默认容易的，深层网络才不会因为"多出来的层把表示搞坏"而退化。
这就是 ResNet 解决"退化问题"的核心：**让新增的层可以选择性地不干活。**

## 第 3 章　表示学习

**1. 为什么 one-hot 向量之间的余弦相似度恒为 0？这对模型意味着什么？**

one-hot 向量只有一个非零分量，且不同词的非零位置不同，点积为 0，范数都为 1，
所以余弦相似度恒为 0。对模型意味着：**所有词两两"同样不相似"**，
它无法利用"猫和狗都是宠物"这种结构，只能把每个词当作独立符号。
这正是 n-gram 无法泛化到未见组合的根源。

**2. BPE 词表设得很大（比如 100 万）和设得很小（比如 1000），各有什么代价？**

- 词表 100 万：嵌入矩阵巨大（$10^6 \times d$），显存与训练成本高；大量低频 token 训练不足；
  但序列短、语义单元完整。
- 词表 1000：嵌入矩阵小、每个 token 训练充分；但同样文本会被切成更多 token，
  序列变长、计算量上升，且语义单元被切碎（一个汉字可能被拆成字节）。
  
权衡的本质是**"词表大小 ↔ 序列长度"**：词表越大，序列越短，但参数越多、稀疏越严重。

**3. "苹果"在"吃苹果"和"苹果发布会"里的向量不同。这个"不同"是在哪一步产生的？**

不在查表那一步——嵌入层对同一个 token 永远返回同一个向量。
不同产生于**后续的注意力层**：每个位置的表示会被上下文"重新混合"，
"苹果"会吸收"吃"或"发布会"的信息，于是同一个词在不同句子中得到不同的**上下文表示**。
这就是"静态词向量"与"上下文相关表示"的分界线。

## 第 4 章　从 RNN 到注意力

**1. 为什么 RNN 的参数量不随句子长度增长？这带来什么好处和什么限制？**

因为 $W_h, W_x$ 在**所有时间步共享**——同一组参数被反复使用。
好处：可以处理任意长度、参数量可控、对位置有一定平移不变性。
限制：必须串行计算（$h_t$ 依赖 $h_{t-1}$），GPU 并行度低；
所有历史被压进固定维度的 $h_t$，形成信息瓶颈。

**2. LSTM 的遗忘门长期接近 1 时，细胞状态近似于什么操作？这为什么有助于梯度传播？**

$c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t$，当 $f_t \approx 1$ 时，$c_t \approx c_{t-1} + \text{新增}$，
即近似**恒等映射 + 加法**。反向传播时，梯度沿这条加法路径回传，
不需要反复乘以 $W_h$ 和 $\tanh'$，因此不会指数衰减。
原文称之为"常数误差传送带"。

**3. 如果把注意力的 softmax 换成"只选分数最高的一个"，会发生什么？为什么通常不这么做？**

会变成 **argmax / 硬注意力**：不可导（"选第 3 个"这个操作没有梯度），无法端到端训练；
而且极其脆弱——分数稍变就切换选择，没有"部分关注"的平滑性；
也无法表达不确定性（模型不能"同时看两个位置"）。
softmax 的加权平均既保留了梯度，又允许软检索，这是注意力能嵌进深度网络的前提。

## 第 5 章　Transformer

**1. 如果把 $QK^\top$ 除以 $d_k$ 而不是 $\sqrt{d_k}$，会发生什么？**

点积的方差是 $d_k$。除以 $d_k$ 会把方差压到 $1/d_k$，logits 全部趋近于 0，
softmax 变得接近**均匀分布**——注意力退化成"对所有权重平均"，模型失去选择性。
反过来，完全不除会让方差为 $d_k$，softmax 饱和成 one-hot，梯度接近 0。
除以 $\sqrt{d_k}$ 恰好把方差拉回 1，让 softmax 工作在"既不饱和也不均匀"的区域。

**2. 多头注意力把 512 维分成 8 个 64 维的头。它比"一个 512 维的头"强在哪里？总计算量变了吗？**

强在**表示子空间的正交性/多样性**：每个头可以学一种不同的关系（语法、指代、位置、语义），
在一个 512 维空间里同时做多种"查询"，最后拼接融合。
单个头只能学一种加权模式，容易被最显著的关系主导。
总计算量**基本不变**：每个头 $d_k=64$，8 个头并行，QKV 投影的总维度仍是 512；
只是把一次大矩阵乘法拆成 8 次小矩阵乘法（工程上更容易并行）。

**3. 为什么说 Transformer 的"弱归纳偏置"既是优点也是缺点？**

优点：不预设"局部性"（CNN）或"顺序递归"（RNN），让数据决定该看哪里，
因此更通用、更容易规模化、能学到人类没预设的模式。
缺点：**需要更多数据才能学好**。弱先验意味着模型要从零发现"语言是有结构的"，
小数据下反而不如强先验的模型。这解释了为什么 Transformer 在 2017 年只是略胜，
要等到 GPT-3 的数据规模才真正起飞。

## 第 6 章　预训练

**1. 为什么 BERT 不能直接用来聊天？从训练目标的角度解释。**

BERT 用**掩码语言模型**训练：输入是被挖了洞的句子，目标是填洞。
它从未学过"给定一个前缀，从左到右续写"。而且它是**编码器**，没有因果掩码，
训练时每个位置都能看到右边——如果直接拿来生成，它会"看到未来"，无法自回归采样。
它的目标函数与"生成"不匹配，所以擅长分类/抽取，不擅长写作/对话。

**2. 自回归目标每个位置都有训练信号，MLM 只有 15%。这个差别为什么在大规模时被放大？**

自回归对长度为 $T$ 的序列产生 $T$ 个预测任务；MLM 只对 15% 的位置产生信号。
同样的 token 预算，自回归的**有效监督量约是 MLM 的 6–7 倍**。
规模越大，这个"数据效率"差异越关键——因为数据是有限资源，
而自回归把每个 token 都用上了。这也部分解释了为什么 GPT 路线在规模化后占优。

**3. "预训练 = 通识教育，微调 = 职业培训"这个类比在哪里失效？**

- 通识教育有课程设计、有教师、有循序渐进；预训练只是"预测下一个词"，没有教学意图。
- 人会**迁移概念**（学会数学后能学物理）；模型迁移的是**统计模式**，
  微调甚至可能"灾难性遗忘"预训练知识。
- 职业培训建立在共同的人类经验上；微调是在一个高维函数上做局部调整，
  两者机制不同。类比能帮你记住"两阶段"，但不能推断"模型像人一样理解"。

## 第 7 章　规模定律

**1. 幂律指数 $\alpha = 0.076$ 意味着什么？参数从 10 亿加到 100 亿，损失大约改善多少？**

$L \propto N^{-0.076}$。参数扩大 10 倍，损失乘以 $10^{-0.076} \approx 0.84$，
即相对下降约 **16%**。绝对下降取决于当前损失值：若损失是 3.0 nat，约降到 2.52 nat。
这个指数很小，说明"规模收益递减"——但因为它是指数关系，绝对改善仍可观。

**2. Chinchilla 的核心结论是什么？它推翻了 Kaplan 的哪一条建议？**

核心结论：参数与训练 token 应**同比例**增长，计算最优配比约为 **20 token/参数**。
它推翻了 Kaplan "固定算力下优先加参数、数据可以少"的建议——那是实验设定偏差
（学习率调度未随训练长度调整）导致的错误结论。

**3. 如果"涌现"是指标假象，那"大模型更强"这件事还成立吗？两者矛盾吗？**

不矛盾。Schaeffer 反驳的是"能力在某个规模**突然**出现"这个**曲线形状**，
不是"大模型更强"这个**单调趋势**。
能力很可能随规模**连续**提升，只是用不连续指标（如 exact match）测量时，
表现成突然跃起。所以："大模型更强"成立；"存在一个神秘的临界点"存疑。

## 第 8 章　RLHF 与对齐

**1. 为什么 RLHF 需要 KL 惩罚？去掉它会发生什么？**

奖励模型只是人类偏好的**代理**，有误差、有漏洞。没有 KL 约束，策略会疯狂优化这个代理：
生成奖励模型喜欢但人类觉得荒谬的文本（奖励黑客），分布迅速偏离原始模型，
输出退化、重复、失去语言能力。
KL 惩罚相当于"你可以调整行为，但别走太远"，把优化限制在原始模型附近的可信区域。

**2. DPO 的推导里，配分函数 $Z(x)$ 为什么能消掉？这个消掉依赖什么前提？**

Bradley–Terry 比较的是**同一个 prompt $x$** 下的两个回答 $y_w, y_l$。
$Z(x)$ 只依赖 $x$，不依赖 $y$，所以在 $r(x,y_w) - r(x,y_l)$ 的差值中正好抵消。
前提是：**比较发生在同一 $x$ 内**（同一个问题下比两个答案）。
如果跨 prompt 比较，$Z(x)$ 不同，就消不掉。

**3. "13 亿参数击败 1750 亿参数"说明了什么？它是否说明参数不重要？**

说明**能力与对齐是两个独立维度**：175B 的 GPT-3 能力更强，但没有被训练成"助手"；
1.3B 的 InstructGPT 更符合人类偏好，所以在"人类觉得哪个回答更好"这个指标上赢。
这不说明参数不重要——在需要知识/推理的任务上，参数仍然是硬约束。
它说明的是：**"讨人喜欢"和"能力强"不是一回事，产品体验取决于前者。**

## 第 9 章　思维链与推理时计算

**1. 为什么"写 100 个 token 的推理"相当于"更深的网络"？请从计算图的角度解释。**

Transformer 的深度固定为 $L$ 层，一次前向只能做 $L$ 层计算。
但自回归生成是**串行**的：第 $t$ 个 token 的生成依赖前 $t-1$ 个 token，
而每个 token 都要过一次完整的 $L$ 层。于是生成 $n$ 个 token 的计算图，
相当于把 $L$ 层重复了 $n$ 次，串行深度约为 $n \times L$。
更重要的是，中间结果被写回上下文，成为下一步的输入——**这相当于给网络加了可读写的"外部工作记忆"**。

**2. 自洽性为什么能提升准确率？它在什么情况下无效？**

如果错误是随机分散的（每条错误路径不同），而正确答案是收敛的，
多数投票就会把正确类选出来（孔多塞陪审团定理的条件）。
无效情况：模型存在**系统性错误**（同一知识点一致地错）、采样高度相关（不独立）、
或者所有路径都错——这时投票只会强化错误。

**3. ReAct 和纯 CoT 的本质区别是什么？为什么这个区别对 Agent 很重要？**

纯 CoT 是**闭卷**的：只在模型内部生成推理，不接触外部世界，无法获取新信息，也无法验证。
ReAct 是**开卷 + 动手**的：Thought → Action → Observation 循环，
观察结果被写回上下文，模型可以据此修正。
对 Agent 重要，因为 Agent 的本质就是"根据环境反馈调整行为"——
没有 Observation，就没有反馈回路，也就没有"智能体"，只有一个"会写计划的模型"。

## 第 10 章　RLVR 与推理模型

**1. RLVR 和 RLHF 的奖励来源有什么本质区别？这如何影响"奖励黑客"的可能性？**

RLHF 的奖励来自**学出来的奖励模型**，它是人类偏好的近似，有误差、可被优化压力钻空子。
RLVR 的奖励来自**确定性验证器**（答案匹配、单元测试），不随策略变化，不会被"讨好"。
所以 RLVR 的奖励黑客空间更小。但并非为零：验证器本身有漏洞
（只检查格式、测试用例太少），模型仍可能"过拟合验证器"。

**2. GRPO 里，如果一组 8 个答案全错，这一步的梯度是什么？这说明了什么训练策略问题？**

奖励全为 0（或全为 1），组内均值等于每个值，标准差为 0，
优势 $A_i = (r_i - \mu)/\sigma$ 无定义或为 0，梯度为 0——**这一步没有学习信号**。
说明训练题目难度必须匹配模型水平：太简单（全对）和太难（全错）都白练。
实践中的对策：过滤掉全对/全错的组、做难度课程、动态调整题目。

**3. 为什么"蒸馏大模型的推理轨迹"可能比"让小模型自己做 RL"更有效？**

小模型做 RL 面临**探索困难**：它很难自己采样出正确的长链推理，奖励稀疏，
可能永远学不到"怎么想"。而蒸馏提供了**密集的、成功的**推理轨迹作为监督，
相当于把大模型搜索到的解直接教给小模型。
这类似"师徒制"：师父已经找到了路，徒弟不必从零试错。

## 第 11 章　效率与架构

**1. MoE 的"总参数"和"激活参数"分别影响什么成本？为什么负载均衡损失是必需的？**

总参数决定**显存/存储**成本（要把所有专家放得下）；激活参数决定**计算/延迟**成本
（每个 token 只算 top-k 个专家）。二者解耦，是 MoE 的经济学基础。
负载均衡损失必需，因为 router 可能 collapse 到少数专家：
其他专家收不到梯度、参数浪费，有效容量反而下降。均衡损失逼迫 router 分散使用专家。

**2. FlashAttention 没有近似，为什么还能快？它优化的是什么？**

它改变了计算顺序：把 Q/K/V 分块，让每块的 softmax、加权求和都在芯片的 SRAM 里一次完成，
不把 $n\times n$ 的中间矩阵写回 HBM 再读出来。
所以它优化的是**显存 IO（读写带宽）**，不是 FLOPs。结果是数值上完全等价，但墙钟时间更短。
核心洞察：**现代 GPU 的瓶颈常常是"搬数据"，不是"算数据"。**

**3. Mamba 和 Transformer 在"记忆"上的取舍，分别对应人类的哪种记忆？**

Transformer 保留全部历史（KV 缓存），可以精确回看任意片段——像**情景记忆**
（episodic memory，具体事件的回放），但存储随长度增长。
Mamba 维护固定大小的状态，边读边压缩——像**语义记忆/笔记**
（semantic memory，抽象出的摘要），存储恒定但细节会丢。
混合架构（多数层 SSM + 少数层注意力）相当于"平时记笔记，关键处翻原始记录"。

## 第 12 章　RAG 与长上下文

**1. 为什么"纯向量检索"在查错误码、专有名词时容易失败？BM25 补了什么？**

嵌入模型把文本压成语义向量，它擅长"意思相近"，但会**抹掉精确字符串**。
"0x80070005"这种罕见 token 在训练中很少见，向量表示很弱，可能被映射到"权限错误"的泛化语义上。
BM25 基于词频与逆文档频率，做的是**精确词项匹配**，能抓住稀有但关键的字符串。
两者互补：向量管语义召回，BM25 管精确召回。

**2. "中间遗失"现象对长文档问答的系统设计有什么直接启示？**

模型对上下文的利用是 U 形的：开头和结尾好，中间差。
启示：(1) 把最关键的证据放在 prompt 的**开头或结尾**；
(2) 用重排器把最相关的块排到两端；
(3) 不要指望"塞进 100 万 token"就等于"读完了"，要分段摘要、迭代检索；
(4) 评测必须覆盖"答案在中间"的情况，否则会高估长上下文能力。

**3. RAG 的"检索错，生成一定错"是否意味着应该放弃 RAG、只用长上下文？为什么？**

不。这句话说明的是**检索是瓶颈**，应该投资于检索质量（混合检索、重排、评测），
而不是放弃这条路。长上下文有自己的问题：成本高、KV 缓存大、中间遗失、注意力被稀释。
两者是不同成本结构的选择，最佳实践通常是**RAG 粗筛 + 长上下文精读 + 引用验证**。
"某环节会失败"不等于"应该删掉这个环节"，而等于"要给它加评测与兜底"。

## 第 13 章　评测与幻觉

**1. 为什么"提高 MMLU 分数"不一定意味着"模型更有用"？请给出至少两个原因。**

(1) **构念效度**：MMLU 是四选一知识题，测的是"知识回忆"，不是推理、写作、工具使用；
(2) **数据污染**：题目可能出现在训练集里，分数反映记忆而非能力；
(3) **饱和与猜测**：分数接近上限后区分度下降，四选一还有 25% 瞎猜基线；
(4) **与真实任务不相关**：用户要的是"帮我改这段代码"，不是"选 B"。

**2. LLM-as-judge 有哪些已知偏见？如何用制度设计缓解？**

偏见：位置偏好（偏爱第一个/最后一个）、长度偏好（偏爱更长）、
自我偏好（偏爱同家族模型）、格式偏好（偏爱排版漂亮的）。
缓解：随机交换 A/B 顺序、隐藏模型身份、多裁判投票、
定期用人类标注做校准、对长度/格式做归一化、报告裁判间一致性。

**3. 幻觉为什么"不可能完全消除"？请从训练目标的角度论证。**

训练目标是最大化"训练语料中下一个 token 的似然"。互联网文本里，
"给出一个看起来像答案的回答"远比"我不知道"常见；错误信息、过时信息也大量存在。
所以模型被优化成**自信地补全**，而不是**标记知识边界**。
RLHF 进一步加剧：人类评分者更喜欢"有问必答"的回答，于是"承认不知道"被惩罚。
只要目标函数不直接奖励"真实性"和"元认知"，幻觉就是结构性副产品，
只能降低概率、提高可检测性，不能归零。

## 第 14 章　机制可解释性

**1. 为什么"一个神经元 = 一个概念"通常是错的？叠加给出了什么解释？**

因为激活维度 $d$ 远小于模型要表示的特征数。如果每个特征占一个正交维度，最多只能表示 $d$ 个。
**叠加**允许用近似正交的方向塞进更多特征，代价是特征之间有干扰。
于是同一个神经元会同时对多个不相关特征响应（多义神经元）。
这不是"混乱"，而是有限维度下的最优压缩。

**2. 线性探针能解码某个概念，能否证明模型"在用"这个概念？还需要什么实验？**

不能。探针只证明"信息**可线性解码**"（相关），不证明"模型**依赖**它做决策"（因果）。
还需要**因果干预**：激活修补（把该方向的激活替换/置零，看输出是否改变）、
消融（ablate 相关头/神经元）、或激活引导（steering）。
只有干预后行为改变，才能说"模型在用"。

**3. 归纳头由哪两个头组成？它如何解释"重复序列续写"？**

由 (1) **前一个 token 头**：位置 $i$ 的注意力专门看 $i-1$，把"前一个 token 是 B"写进表示；
(2) **归纳/匹配头**：用"我前面是 B"去匹配历史中 B 出现的位置，把 B 后面的 token 复制过来。
组合起来实现"如果这个模式之前出现过，就照抄它后面跟的内容"。
这就是"重复序列续写"和部分 in-context learning 的机制。

## 第 15 章　智能体与前沿

**1. 为什么"给 agent 更多工具"可能让它更不安全，也可能让它更笨？**

更不安全：工具扩大攻击面（提示注入、越权操作、数据外泄），
每个工具都是一条"能造成副作用"的路径。
更笨：工具描述占用上下文、增加选择难度（路由错误）、增加出错环节（复合误差），
模型可能在不该调用时调用、参数填错、或陷入"工具调用循环"。
工具不是越多越好，而是要**匹配任务、权限最小化、返回信息简洁**。

**2. 复合误差的公式是什么？举一个你身边的"多步流程失败"的例子。**

串联可靠度 $R = \prod_{i=1}^{n} R_i$。每步 95%、20 步：$0.95^{20} \approx 0.358$。
例子：一次转机旅行——打车准时、值机、安检、第一段航班、转机、第二段航班、行李提取，
每步 95%，全程顺利的概率只有约 70%；任何一步延误，整条链断裂。
所以航空业用**冗余**（备降机场、改签）和**检查点**（每段确认）来对抗。

**3. 提示注入为什么难以根治？请从 Transformer 的输入机制解释。**

Transformer 的输入是**一个扁平的 token 序列**，系统提示、用户消息、网页内容、工具返回，
最终都被拼成同一种 token，进入同一个注意力机制。
模型没有任何"硬件级"的通道来区分"这是指令"和"这是数据"。
而它又被训练成"遵循文本中的指令"，所以任何文本都可能被当作指令执行。
SQL 注入可以用参数化查询把数据和代码分开；LLM 目前没有等价的可靠机制，
只能靠权限最小化、沙箱、人工确认来限制爆炸半径。

## 第 16 章　综合题

**1. 用不超过 200 字，向一个完全不懂的人解释：为什么"预测下一个词"能产生推理能力？
要求至少用到本课程的三个概念。**

> 模型每次只做一件事：根据上文猜下一个词。但要猜得准，它必须在内部算出有用的中间结果——
> 比如"这句话在问数学题""这两个数应该相加"。**注意力**让它能从长上文里找到相关线索；
> **思维链**让它把中间步骤写出来，每写一个词就多算一次，等于"多想几步"；
> **规模定律**说模型越大、数据越多，这种计算就越精细。
> 当训练数据里有大量解题过程，而**强化学习**又奖励"答对"时，
> 它就会自发学会"先拆解、再计算、最后检查"。所以推理不是被教会的，
> 而是"为了猜得更准"被逼出来的副产品。

**2. 如果明天所有 GPU 算力突然减半，LLM 的发展会往哪个方向走？请用至少三条定律论证。**

> (1) **定律 4（规模有边界）**：训练更大模型的收益递减，算力减半会让"堆参数"更不划算；
> (2) **定律 6（推理可写进权重，也可花在推理时）**：训练预算紧张时，
> 更倾向于把小模型训练好（蒸馏、RL），而不是训练大模型；
> (3) **定律 7（稀疏是效率的通用解）**：MoE、量化、GQA、FlashAttention 的优先级会更高；
> (4) **定律 8（记忆分层）**：用 RAG/外部库替代"把所有知识塞进参数"，因为存参数比重算便宜。
> 总体方向：**从"更大"转向"更省 + 更会查 + 更会想"**，小模型 + 长上下文 + 工具会成为主流。

**3. 选一个你熟悉的领域（医学、法律、教育、艺术……），说出它和 LLM 的一个同构结构，
并指出这个类比在哪里失效。**

> 示例（医学）：**鉴别诊断 ≈ 束搜索（beam search）**。
> 医生根据症状列出几个候选诊断（生成多个假设），用检查结果给每个假设打分（评估器），
> 保留最可能的几个继续追问（剪枝），必要时回头（回溯）。
> 失效处：医生有**因果模型**（病理生理机制），能区分"相关"与"因果"；
> LLM 只有**统计关联**，它的"诊断"可能抓住了一个虚假相关的特征。
> 医生还要为决策**负责**，而模型没有责任主体——这是制度差异，不是能力差异。
