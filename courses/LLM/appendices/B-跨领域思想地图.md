# 附录 B　跨领域思想地图

> 这份地图整理的是：**LLM 的核心概念，在人类其他领域里以什么面貌出现过。**
>
> 每一行都包含两列：**同构点**（结构上哪里一样）和**边界**（类比在哪里失效）。
> 只写"像什么"而不写"哪里不像"，是科普最常见的偷懒，也是误解的主要来源。
>
> 为什么值得这样做？认知科学的**结构映射理论**（structure-mapping theory, Gentner 1983）指出：
> 类比迁移的不是表面特征，而是**关系结构**。你越能在陌生领域里认出熟悉的关系结构，
> 学习就越快。但同一个理论也警告：**表面相似而结构不同的类比，会系统性地误导人。**

---

## B.1 物理与热力学

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| 交叉熵 / 困惑度（§1.4） | **热力学熵** | 克劳斯修斯 1865；玻尔兹曼 1877 | 都是"不确定/无序"的度量；$S=k\log W$ 与 $H=-\sum p\log p$ 形式同构 | 热力学熵有明确的物理单位与演化方向（第二定律）；信息熵没有"必然增加"的定律 |
| softmax / 温度（§1.6） | **玻尔兹曼分布** | 玻尔兹曼 1868 | $p_i\propto e^{-E_i/kT}$ 与 $e^{z_i/\tau}/\sum e^{z_j/\tau}$ 逐项对应 | 物理的 $T$ 是真实温度，$\tau$ 只是超参；物理能量守恒，logit 不守恒 |
| DPO 的闭式解（§8.5） | **自由能最小化 / 配分函数** | 吉布斯 1870s | 最优策略 $\propto \pi_{\text{ref}}e^{r/\beta}$ 就是玻尔兹曼分布；KL 正则 = 熵项 | 物理能量给定，RLHF 的奖励是学出来的、可被 hack；物理没有"奖励模型" |
| 训练中的随机性（§2.2） | **模拟退火** | 柯克帕特里克 1983 | 先高温探索、后低温收敛；用噪声跳出局部极小 | 退火有明确的降温日程与收敛保证；SGD 的"温度"（学习率）没有理论最优 schedule |
| 梯度下降（§2.1） | **最小作用量原理** | 莫佩尔蒂 1744；欧拉-拉格朗日 | 都是"沿某个泛函的极值方向演化" | 最小作用量是**全局**变分原理；梯度下降是**局部**迭代，会卡在局部极小 |
| 涌现能力（§7.4） | **相变 / 临界现象** | 朗道 1937；渗流理论 1957 | 参数连续变化、宏观性质突变；临界点附近幂律 | 相变有严格的热力学定义与序参量；LLM 的"涌现"可能只是指标不连续（§7.4） |
| 缩放定律（§7.2） | **异速生长律 / Kleiber 定律** | Kleiber 1932 | 都是跨多个数量级的幂律；双对数坐标下是直线 | 代谢律有分形网络的理论解释；LLM 的幂律目前只有经验拟合，没有第一性原理 |
| 模型规模与能耗 | **热力学效率极限** | 兰道尔 1961 | 信息擦除有最小能量代价（$kT\ln 2$） | 当前 LLM 的能耗离兰道尔极限差十几个数量级，工程约束远早于物理约束生效 |

## B.2 信息论与压缩

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| 交叉熵损失（§1.4） | **香农信源编码** | 香农 1948 | 交叉熵 = 用错误分布编码真实分布的平均码长 | 香农只关心"传输"，不关心"意义"；LLM 的"意义"是副产品 |
| BPE 分词（§3.5） | **数据压缩 / 字节对编码** | Gage 1994 | 都是"反复合并最高频符号，用短码表示高频模式" | 压缩追求最短编码；分词还要保证可逆性、跨语言覆盖、与嵌入维度匹配 |
| 权重共享 / 嵌入压缩 | **率失真理论** | 香农 1959 | 压缩率与失真之间存在权衡曲线 | 率失真定义在明确的失真度量上；LLM 的"失真"由下游任务定义，不唯一 |
| 叠加现象（§14.3） | **压缩感知** | Candès–Romberg–Tao 2006 | 稀疏信号可以用远少于维度的测量恢复；高维随机向量近似正交 | 压缩感知有严格的恢复保证（RIP 条件）；SAE 的解混没有同等级的理论保证 |
| 困惑度（§1.4） | **每字符比特数（bits per character）** | 香农 1951 | 香农估计英文熵约 0.6–1.3 bit/字符；今天 LLM 的 bpc 已低于此估计 | 香农的估计基于人类被试的猜测实验，不是模型；两者不可直接比较 |
| 词表大小（§3.5） | **编码字典设计** | 赫夫曼 1952 | 高频符号用短码，低频用长码组合 | 赫夫曼码是前缀码，保证无歧义解码；BPE 词表不保证语义最优 |

## B.3 数学与统计

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| 最大似然（§1.5） | **Fisher 极大似然** | Fisher 1912 | 最小化负对数似然 = 最大化数据似然 | 最大似然在模型误设时不一定最优；LLM 的模型必然误设 |
| KL 散度（§1.4） | **相对熵 / 信息增益** | Kullback–Leibler 1951 | 衡量"用 q 代替 p"的额外代价；非负、不对称 | KL 不是距离（不满足对称性与三角不等式）；实践中常用反向 KL，行为完全不同 |
| 缩放定律（§7.2） | **Zipf 定律 / 帕累托分布** | Zipf 1935；Pareto 1896 | 都是跨尺度的幂律；少量事件占大部分质量 | Zipf 描述的是**分布**，scaling law 描述的是**性能随规模的变化**，机制不同 |
| 反向传播（§2.3） | **动态规划** | Bellman 1950s | 复用子问题结果，避免重复计算；反传缓存上游梯度 | DP 要求最优子结构并可枚举状态；反传的计算图是固定的，不需要搜索状态空间 |
| GRPO 的组内基线（§10.3） | **控制变量法 / 方差缩减** | 蒙特卡洛方法，1940s | 减去一个期望为零的基线，不改变梯度期望、只降低方差 | 控制变量需要与目标相关的基函数；GRPO 只用组内均值，是特例 |
| 激活修补（§14.6） | **因果推断 / do-calculus** | Pearl 1995 | 区分"观察到"与"干预"；用干预估计因果效应 | do-calculus 要求因果图已知；LLM 的因果图未知，激活修补只是局部干预 |
| 线性探针（§14.6） | **相关 vs 因果** | 统计学基本区分 | 能解码 ≠ 被使用 | 探针可能学到"模型没用的信息"；需要激活修补补充因果证据 |
| 高维嵌入（§3） | **Johnson–Lindenstrauss 引理** | Johnson & Lindenstrauss 1984 | 高维点集可嵌入低维而近似保距；高维随机向量近似正交 | JL 保证的是**距离**保持，不保证**语义**保持 |

## B.4 控制论与工程

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| RNN 隐藏状态（§4.2） | **状态空间模型 / 卡尔曼滤波** | Kalman 1960 | $h_t = f(h_{t-1}, x_t)$ 与线性高斯状态空间同构 | 卡尔曼滤波有最优性证明（线性高斯下）；RNN 没有 |
| Agent 循环（§15.1） | **OODA 循环** | Boyd 1970s | 观察—判断—决策—行动，快速迭代 | OODA 假设有一个统一的"判断者"；LLM agent 的"判断"与"行动"共享同一套 token 生成 |
| Agent 循环（§15.1） | **负反馈控制** | Wiener 1948 | 根据输出与目标的偏差调整下一步 | 经典控制有稳定性理论；LLM agent 的稳定性没有数学保证 |
| 残差连接（§2.4.4） | **旁路 / 飞扶壁** | 建筑：12 世纪哥特 | 不改变主结构，另开一条力流/梯度通道 | 飞扶壁承受的是静态侧推力；残差传的是动态梯度，且会累加噪声 |
| FlashAttention（§11.4） | **CPU 缓存层级 / 局部性原理** | 1960s–80s | 把反复使用的数据放在快而小的存储里，减少搬运 | 缓存命中率由访问模式决定；FlashAttention 的分块是算法层面的确定性重排 |
| 流水线并行（§5.7） | **福特流水线** | 福特 1913 | 把串行工序改成可并行的工序，提高吞吐 | 流水线有启动/排空开销与同步成本；Transformer 的并行是数据级而非工序级 |
| 复合误差（§15.5） | **串联系统可靠度** | 可靠性工程，1950s | $R=\prod R_i$，环节越多越不可靠 | 工程系统可以加冗余；LLM agent 的"冗余"（多采样）成本高且不独立 |
| 数据污染（§13.4） | **考试泄题 / 题库安全** | 教育测量学 | 测试题泄漏会高估能力 | 考试有题库轮换与等值设计；LLM 评测的更新速度远慢于训练数据增长 |
| 提示注入（§15.6） | **SQL 注入 / 社会工程** | 1998 / 1970s | 数据被当成指令执行；利用"无法区分信息与指令" | SQL 有参数化查询这一可靠解法；LLM 目前没有等价的硬隔离机制 |
| MCP（§15.2） | **集装箱标准化 / USB** | 1956 / 1996 | 统一接口降低适配成本，形成生态 | 标准也可能锁定劣质方案（QWERTY 效应）；协议竞争有路径依赖 |
| 注意力（§4.6） | **数据库查询 / 软检索** | 数据库理论，1970s | 用 key 查找、返回 value；注意力是"软匹配 + 加权平均" | 数据库是精确匹配、返回单条；注意力是可微的、返回所有 value 的加权和 |

## B.5 生物与进化

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| SGD 的噪声（§2.2） | **细菌趋化性** | Berg & Brown 1972 | 无地图、只有局部梯度、靠噪声探索 | 细菌的"目标函数"是生存，天然多目标；SGD 只有一个标量损失 |
| LSTM 的加法更新（§4.3） | **增量编辑 / 版本控制 diff** | 软件工程 | 默认保留，只改局部，保护主干 | 版本控制有完整历史与回滚；LSTM 的状态是连续向量，没有"版本"概念 |
| 预训练（§6.6） | **预适应（exaptation）** | Gould & Vrba 1982 | 为 A 功能演化的结构被复用于 B 功能 | 进化没有"目标函数"，是盲目变异 + 选择；预训练有明确损失函数 |
| MoE（§11.2） | **神经稀疏编码** | 嗅觉系统研究，1960s– | 少数神经元同时活跃，省能量、减干扰 | 生物稀疏性有代谢与发育约束；MoE 的稀疏是人为设定的 top-k |
| 蒸馏（§10.5） | **师徒制 / 遗传** | 人类文明 | 少数探索者的成果被多数人复制 | 生物遗传是基因复制；蒸馏是行为/输出复制，学不到"探索过程" |
| RLHF（§8） | **驯化** | 约 1.5 万年前 | 用选择压力改变种群行为，而非直接设计 | 驯化是跨代选择；RLHF 是单代梯度更新，且"选择者"是奖励模型 |
| 记忆分层（§15.3） | **情景/语义/程序性记忆** | Tulving 1972 | 事实、事件、技能分开存储 | 大脑的三类记忆共享同一套神经元；LLM 的三层是物理上分离的系统 |
| 模型规模（§7） | **Kleiber 定律** | Kleiber 1932 | 代谢率 $\propto M^{3/4}$，与 loss $\propto N^{-\alpha}$ 都是跨尺度幂律 | Kleiber 有分形输运网络解释；LLM 的指数没有公认的机制解释 |

## B.6 神经科学与心理学

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| 注意力（§4.5） | **选择性注意 / 过滤器模型** | Broadbent 1958；Posner 1980 | 信息过载时，给相关刺激更高权重 | 人的注意力有资源限制与意识体验；注意力的 softmax 是无意识的数值运算 |
| 注意力（§4.5） | **赫伯特·西蒙的"注意力经济"** | Simon 1971 | "信息越丰富，注意力越贫乏"——选择比获取更难 | 西蒙讲的是人类与组织的资源配置；LLM 的注意力是固定预算的加权平均 |
| 自注意力（§5.2） | **鸡尾酒会效应** | Cherry 1953 | 能在嘈杂中聚焦特定声源 | 鸡尾酒会是**单通道选择**；自注意力是**全通道加权** |
| 上下文窗口（§7.5） | **工作记忆 7±2** | Miller 1956 | 容量有限、易被覆盖的临时存储 | Miller 的"组块"依赖长时记忆；LLM 的窗口是硬性的 token 数 |
| 中间遗失（§12.4） | **首因/近因效应** | Ebbinghaus 1885；Murdock 1962 | 序列中部信息回忆最差，呈 U 形 | 人类效应来自复述与记忆衰减；LLM 来自注意力权重与训练分布 |
| 幻觉（§13.5） | **虚构症（confabulation）** | 神经心理学，20 世纪 | 生成自洽但虚假的叙事，且坚信不疑 | 人类虚构症有明确的脑损伤基础；LLM 的"虚构"是目标函数的自然结果 |
| 思维链（§9.2） | **出声思考（think-aloud）** | Ericsson & Simon 1980s | 把序列化的思维外显，帮助解决问题 | 人类出声思考会改变思考本身（反应性）；LLM 的 CoT 不保证忠实 |
| 思维链（§9.2） | **系统 1 / 系统 2** | Kahneman 2011 | 快直觉 vs 慢推理；CoT 像系统 2 | Kahneman 的双系统是两种不同机制；LLM 只有一种机制，只是多跑几步 |
| 思维树（§9.4） | **手段—目的分析** | Newell & Simon 1972 | 把大目标拆成子目标，搜索解路径 | 人类的子目标分解依赖领域知识；ToT 的评估器可能和生成器一样不可靠 |
| 预训练（§6.2） | **格式塔闭合** | 格式塔心理学，1920s | 残缺图形/句子会被自动补全 | 格式塔讲的是知觉组织；MLM 是统计共现的学习 |
| RLVR（§10.2） | **效果律 / 操作性条件反射** | Thorndike 1911；Skinner 1938 | 带来好结果的行为被强化 | 行为主义拒绝研究内部表征；RLVR 的模型内部有丰富表征 |
| RLVR 的"顿悟"（§10.2） | **顿悟学习** | Köhler 1925 | 突然重组问题表征，找到解法 | 苛勒强调"整体重组"；RLVR 的顿悟可能只是长期试错的相变表现 |
| 多智能体（§15.4） | **传话游戏 / 组织信息损耗** | 心理学实验，1960s | 每经一次转述，信息损失一次 | 人类转述有意图与创造；LLM 的转述是概率压缩 |
| 可解释性（§14.1） | **单细胞记录 / 视觉皮层** | Hubel & Wiesel 1959 | 从神经元响应推断计算功能 | 神经科学不能任意干预人脑；可解释性可以随意消融、替换激活 |
| RAG / 工具（§12、§15） | **延展心智（extended mind）** | Clark & Chalmers 1998 | 认知过程可以延伸到身体之外的工具与记录上 | 延展心智讨论的是"认知的边界"这一哲学问题；RAG 只是工程上把外部文本放进上下文 |

## B.7 语言学

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| 词向量（§3.2） | **分布语义学** | Firth 1957；Harris 1954 | "观其伴，知其义"：上下文定义意义 | 分布语义学是语言学理论；词向量是它的工程实现，且会放大数据偏见 |
| 词向量类比（§3.3） | **语义空间 / 语义 differential** | Osgood 1952 | 用多维空间中的位置表示意义 | Osgood 的维度有人类标注的语义（评价/ potency / activity）；word2vec 的维度不可解释 |

| 位置编码（§3.8） | **语序 / 格语法** | 语言学传统 | 顺序改变意义（"猫追狗" vs "狗追猫"） | 语言学有层级句法树；位置编码只是给序列位置一个向量 |

| 上下文学习（§7.5） | **类比推理** | 认知语言学 | 给几个例子，推断规则并应用 | 人类类比依赖关系结构（Gentner）；ICL 可能只是模式匹配 |

## B.8 经济与管理

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| MoE（§11.2） | **亚当·斯密的分工** | 1776 | 专业化 + 协调，总产出大于各自独立 | 分工需要市场协调；MoE 的路由是集中式学习的，不是价格机制 |
| MoE 负载均衡（§11.2） | **比较优势 / 运筹学负载均衡** | Ricardo 1817 | 让每个单元做相对更擅长的事，避免闲置 | 比较优势假设要素不流动；MoE 的路由可以随时改变分配 |
| RLHF（§8.7） | **委托—代理问题** | 经济学，1970s | 委托人想要 A，代理人被激励做 B；需要机制设计 | 经济学假设代理人有策略性；模型的"策略性"是优化压力的副产品 |
| 奖励黑客（§8.4） | **Goodhart / Campbell 定律** | Goodhart 1975；Campbell 1979 | 指标成为目标后失效 | 经济学讨论的是社会系统；模型是单 agent 对固定指标的优化 |
| 评测（§13.3） | **显示性偏好** | Samuelson 1938 | 不问你要什么，看你选什么 | 显示性偏好假设选择揭示真实偏好；RLHF 的标注者可能被引导 |
| Elo / Bradley–Terry（§8.3） | **国际象棋等级分** | Elo 1978；Bradley–Terry 1952 | 一个标量概括实力，分数差预测胜率 | Elo 假设实力稳定；模型在不同任务上的"实力"不可用一个标量概括 |
| 数据墙（§7.6） | **石油峰值** | Hubbert 1956 | 资源有限、开采成本递增，需要转型 | 石油不可再生；文本数据可以被合成、被重新标注 |
| 规模经济（§7） | **学习曲线 / 经验曲线** | 1936（航空制造） | 产量翻倍，单位成本按固定比例下降 | 学习曲线靠工艺改进；scaling law 靠参数与数据增加，机制不同 |
| 小模型 + 多数据（§7.3） | **木桶效应 / Liebig 最小因子定律** | Liebig 1840 | 产量由最稀缺要素决定 | 木桶效应假设要素不可替代；参数与数据在某种程度上可替代 |

## B.9 哲学与科学方法

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| 正则化（§2.5） | **奥卡姆剃刀** | 奥卡姆 14 世纪 | 如无必要，勿增实体；简洁的理论更可信 | 奥卡姆剃刀是方法论原则；L2 正则是一个可优化的惩罚项 |
| 涌现（§7.4） | **突现论（emergence）** | 19 世纪哲学；复杂性科学 | 整体性质不能由部分性质线性推出 | 哲学突现论常带本体论承诺；LLM 的"涌现"是可测量的行为现象 |
| 评测（§13.7） | **操作化定义** | Bridgman 1927 | 概念的意义等于测量它的操作 | 操作化会窄化概念（"智力 = IQ 分数"）；benchmark 同样窄化"能力" |
| 评测（§13.7） | **可证伪性** | Popper 1934 | 一个主张要能被反例推翻才有意义 | 评测不是假设检验；"模型会不会推理"很难设计出干净的证伪实验 |
| 范式转移（§16） | **库恩的科学革命** | Kuhn 1962 | 旧范式积累反常，新范式整体替换 | 库恩讲的是科学共同体；技术路线更替还受算力、资本、生态影响 |
| 苦涩的教训（§16） | **经验主义 vs 理性主义** | 哲学史 | 数据驱动 vs 先验设计 | Sutton 的立场是极端的经验主义；它无法解释"为什么某些架构更有效" |

## B.10 艺术、建筑与化学

| LLM 概念 | 跨领域对应 | 提出者 / 年代 | 同构点 | 边界（失效处） |
|---|---|---|---|---|
| 残差连接（§2.4.4） | **哥特式飞扶壁** | 12 世纪 | 外加一条力流通道，不改变主结构 | 建筑是静态平衡；网络是动态梯度流 |
| 位置编码（§3.8） | **乐谱小节线** | 记谱法，11–13 世纪 | 同样的音，落在不同小节，意义不同 | 小节线是离散标记；位置编码是连续向量加法 |
| 多头注意力（§5.4） | **棱镜分光** | 牛顿 1666 | 把混合信号分解成不同成分，分别处理后合成 | 棱镜分光是物理分解；多头是学出来的线性投影，没有"频率"含义 |
| 词向量（§3.3） | **地图投影** | 墨卡托 1569 | 为了保留某种关系（角度/相似度），牺牲另一种（面积/原义）；没有"完美"的表示 | 投影是确定性的数学变换；嵌入是学出来的，会随数据漂移、继承偏见 |
| SAE（§14.4） | **色谱分析** | Tsvet 1900 | 让混合物通过介质，按不同速度分离 | 色谱有明确的物理分离机制；SAE 的"分离"依赖稀疏性假设 |
| 蒸馏（§10.5） | **酿酒蒸馏** | 古代 | 从大量原料中提取精华 | 蒸馏是物理提纯；模型蒸馏是函数逼近 |
| FlashAttention（§11.4） | **厨房备菜（mise en place）** | 烹饪传统 | 把要用的材料先放到手边，减少来回跑 | 备菜是空间组织；FlashAttention 是显存层级的数据调度 |
| 量化（§11.6） | **有损压缩（JPEG/MP3）** | 1980s–90s | 丢掉不敏感的信息，换取体积/带宽 | JPEG 的失真度量基于人眼；量化的"可接受失真"取决于下游任务 |
| 上下文工程（§12.5） | **编辑/摘录** | 出版传统 | 选什么、放多少、怎么排序，决定读者能获得什么 | 编辑面向人类读者；上下文面向模型，其"注意力"分布不同 |

## B.11 类比的三种正确用法

1. **用类比建立直觉**：先让你"感觉"到概念在做什么。
   例：把注意力说成"可微的字典查询"。
2. **用类比预测结构**：如果两个系统结构同构，那么一个系统的已知性质可能迁移。
   例：从玻尔兹曼分布预测 DPO 的最优解形式——这是**真正有生产力**的用法。
3. **用类比发现边界**：追问"哪里不一样"，往往能揭示新机制。
   例：物理能量守恒，logit 不守恒——这个差异指向"奖励模型可以被 hack"。

## B.12 类比的三种误用

1. **表面相似当结构相同**：把"神经网络像大脑"当成"神经网络就是大脑"。
   两者共享"大量简单单元 + 加权连接"，但学习规则、稀疏性、可塑性都不同。
2. **用类比代替证明**：说"注意力像人眼，所以它能理解"。
   类比只能提供假设，不能提供证据。**证据必须来自实验与评测。**
3. **忽略尺度差异**：把"细菌趋化性"直接等同于"梯度下降"。
   细菌没有全局损失函数，也没有反向传播；同构只在"局部梯度 + 噪声探索"这一层。
