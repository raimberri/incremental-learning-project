## 5.1 一个激进的问题

第 4 章结尾留下了一个尴尬的局面：注意力是在 RNN 上面打的补丁。
编码器仍然要一个词一个词地读，解码器仍然要一个词一个词地写。

2017 年，Google 的八位作者在《Attention Is All You Need》里问：

> **既然注意力已经能建立任意两个位置之间的联系，为什么还需要循环？**

他们的回答是：不需要。把循环整个删掉，只用注意力，效果更好，而且**能并行**。

这篇论文的标题本身就是论点。它没有说"注意力很有用"，而是说"你需要的**只有**注意力"。

## 5.2 自注意力：一句话内部互相看

第 4 章的注意力是"解码器看编码器"，跨两条序列。
Transformer 把它改成**同一条序列内部互相看**，叫**自注意力**（self-attention）。

对句子里的每个词，我们都问三个问题：

- 我在找什么？（**Query**，查询）
- 我有什么可以被找？（**Key**，键）
- 如果被找到，我提供什么内容？（**Value**，值）

三个向量都由同一个词向量乘上三个不同的矩阵得到：

$$
Q = XW_Q,\qquad K = XW_K,\qquad V = XW_V
$$

其中 $X$ 是整句的矩阵（每行一个词向量）。$W_Q, W_K, W_V$ 是**可训练参数**。

于是"猫"这个位置的 Query，会和句子里每个位置的 Key 做匹配，
匹配度决定它从每个位置的 Value 里取多少信息。

> **和第 4 章的区别**：Bahdanau 的注意力是"跨序列检索"，Q 来自解码器、K/V 来自编码器；
> 自注意力是"序列内检索"，Q/K/V 来自同一句话。结构一样，用途不同。
> 后者更通用：它让每个词都能根据上下文**重新定义自己**。

例：

```
句子：  小 明 把 书 放 在 桌 上 ， 因为 它 太 重 了
                                              ↑
                                       "它"指书还是桌子？
```

"它"这个位置的 Query 会去匹配所有 Key。如果"书"的 Key 得分更高，
"它"的表示就会吸收更多"书"的信息，后续层就能据此判断"重"说的是书。
**这就是"消解指代"在机制层面的样子**——不是靠规则，而是靠学出来的匹配。

## 5.3 缩放点积注意力：一行公式

Transformer 把 Bahdanau 的小型神经网络打分，换成了最简单的**点积**：

$$
\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

逐项读：

1. $QK^\top$：每对 (query, key) 的点积，得到一个 $n\times n$ 的分数矩阵（$n$ 是序列长度）。
   点积衡量方向一致性——两个向量越"同向"，得分越高。
2. 除以 $\sqrt{d_k}$：缩放。原因见下。
3. 按行做 softmax（§1.6 已讲）：每行变成一组和为 1 的权重。
4. 乘 $V$：按权重把 value 加起来。

### 为什么必须除以 $\sqrt{d_k}$

假设 $q$ 和 $k$ 的每个分量都是独立的、均值 0、方差 1 的随机数。
那么点积 $q\cdot k = \sum_{i=1}^{d_k} q_i k_i$ 的方差是 $d_k$。
$d_k = 64$ 时，点积的标准差约为 8——也就是说，分数会散布在 $[-24, 24]$ 这种范围里。

把这么大的数喂给 softmax 会发生什么？softmax 会变得极其"尖锐"：
最大值那一项接近 1，其余接近 0。而 softmax 在饱和区的**梯度接近 0**（§4.2 的梯度消失问题再次出现）。

除以 $\sqrt{d_k}$ 把方差拉回 1，softmax 就工作在"有梯度"的区域。

> **一句话**：缩放不是为了数值稳定，是为了**别让 softmax 提前饱和**。
> 这是一个"工程细节决定成败"的典型例子——删掉这个根号，训练会明显变差。

## 5.4 多头注意力：同时从几个角度看

一组 Q/K/V 只能学一种"相关性"。但语言里的关系是多种多样的：
语法主谓、指代、语义相似、位置邻近……

**多头注意力**（multi-head attention）的做法是：把 $d$ 维分成 $h$ 份，
每份独立做一次注意力，最后拼起来，再过一个线性层。

$$
\mathrm{MultiHead}(Q,K,V) = \mathrm{Concat}(\text{head}_1,\dots,\text{head}_h)W_O
$$

原论文 $d_{\text{model}} = 512$，$h = 8$，每个头 $d_k = 64$。
总计算量和"一个 512 维的头"差不多，但表达能力更强。

> **跨领域对照**　像一个**多学科会诊**：同一份病历，心内科看心电图、影像科看 CT、
> 检验科看血象，各自关注不同维度，最后主治医生综合。
> 也像**棱镜分光**：白光（原始表示）被分成不同频率，各自处理后重新合成。
> 但注意边界：这些"头"并没有被指定去看什么，分工是训练后**自发涌现**的。
> 有些头确实学出了句法角色，也有很多头的作用至今说不清（第 14 章）。

## 5.5 一个必须补上的零件：位置

自注意力有一个数学性质：**它对输入顺序是等变的**（permutation equivariant）。
把句子里的词打乱，"每个词对所有词的加权和"这件事本身不会变——
因为点积不知道谁在前谁在后。

所以必须把位置信息显式加进去（§3.8 已解释为什么需要位置编码）。
原论文用的是正弦/余弦编码，它直接**加到**词向量上，然后一起送进网络（公式见 §3.8，不重复）。
选择三角函数的理由之一是：对任意固定偏移 $k$，$PE_{i+k}$ 可以表示为 $PE_i$ 的线性函数，
模型因此容易学会"相对位置"的概念。

后来的模型多用**可学习位置嵌入**或 **RoPE**（旋转位置编码）。
RoPE 的做法是把 query 和 key 按位置"旋转"一个角度，
使得它们的点积只依赖于**相对位置** $i-j$。细节不展开，记住一点即可：
**位置信息可以编码进注意力打分本身，而不只是加在输入上。**

## 5.6 把零件组装成一个 Block

一个 Transformer 层（block）由两个子层组成，每个子层都套着"残差 + 归一化"：

```
x ──┬──→ LayerNorm → 多头自注意力 → ┬──→ x'
    └────────── 残差 ──────────────┘
x' ─┬──→ LayerNorm → 前向网络(FFN) → ┬──→ x''
    └────────── 残差 ──────────────┘
```

### 前向网络（FFN）

$$
\mathrm{FFN}(x) = W_2\,\phi(W_1 x + b_1) + b_2
$$

先升维到 $4d$，过非线性（ReLU 或 GELU），再降回 $d$。
它对每个位置**独立**作用，不跨位置交流。

> 注意分工：**注意力负责"位置之间交换信息"，FFN 负责"每个位置内部做变换"。**
> 前者是横向的，后者是纵向的。后来的可解释性研究发现，
> FFN 很像一个"键值记忆库"：第一层权重匹配模式，第二层权重存储内容。
> 这为第 14 章埋下伏笔。

### 归一化放在哪：Post-LN vs Pre-LN

原论文是 **Post-LN**：先做子层，再残差，最后 LayerNorm。
后来的大模型几乎都改成 **Pre-LN**：先 LayerNorm，再做子层，最后加残差。

$$
\text{Post-LN: } x \leftarrow \mathrm{LN}(x + F(x)),\qquad
\text{Pre-LN: } x \leftarrow x + F(\mathrm{LN}(x))
$$

原因：Pre-LN 让残差路径上**没有归一化**，梯度可以沿着恒等连接一路直通底层（§2.4.4 的思想），
深层模型训练更稳，甚至可以不用学习率预热。
代价是表达能力略降，通常用更多层来补偿。

> 现在的 LLM 还常用 **RMSNorm**：去掉均值中心化，只除以均方根。
> 更便宜，效果相当。这是"归一化"这一族方法在工程压力下的极简演化。

## 5.7 因果掩码：为什么训练能并行，生成却要逐步

语言模型不能看未来。训练时，如果让位置 3 看到位置 4 的词，那就是作弊。
解决办法是**因果掩码**（causal mask）：在 softmax 之前，
把分数矩阵的右上三角全部设成 $-\infty$。

```
        看得到的位置
       1  2  3  4
    1  ✓  ✗  ✗  ✗
    2  ✓  ✓  ✗  ✗
    3  ✓  ✓  ✓  ✗
    4  ✓  ✓  ✓  ✓
```

这样位置 $t$ 只能注意到 $\le t$ 的位置，和自回归生成（§1.2）的约束一致。

**这里有一个极漂亮的工程事实**：训练时，一整句话的所有位置可以**同时**计算，
因为掩码保证了每个位置看不到未来。一次前向传播，就得到了 $n$ 个位置的预测，
可以同时算 $n$ 个损失。

相比之下，RNN 必须算完 $h_1$ 才能算 $h_2$。**同样的 GPU，Transformer 的利用率高出一个数量级。**
这是它取代 RNN 的最直接原因，也是最容易被忽视的原因——不是"更聪明"，而是"更能吃算力"。

> **跨领域对照**　这是**流水线并行**（pipeline parallelism）对**串行装配**的胜利。
> 福特 1913 年的流水线之所以革命性，不是因为工人更强，而是因为工序可以同时进行。
> Transformer 把"读句子"从串行工序改成了并行工序，代价是需要更多内存（存整个 $n\times n$ 矩阵）。

---

## 5.8 代价：二次复杂度

注意力要算 $n\times n$ 的分数矩阵。序列长度翻倍，计算量和内存都变成 4 倍。

| 部件 | 计算量 | 说明 |
|---|---|---|
| 自注意力 | $O(n^2 d)$ | 长度平方，长文本的瓶颈 |
| FFN | $O(n d^2)$ | 与长度线性 |

所以：

- 短序列时，FFN 是主要开销；
- 长序列时，注意力迅速成为瓶颈。

这直接催生了第 11 章的一堆效率技术（FlashAttention、GQA、稀疏注意力、线性注意力、Mamba），
以及第 12 章的长上下文问题。

---

## 5.9 为什么是 Transformer 赢了

把原因列清楚，因为这是一道常考的"为什么"：

1. **并行**：训练时所有位置同时算，GPU 利用率高。
2. **短路径**：任意两个位置之间只隔一层注意力，路径长度 $O(1)$；
   RNN 里是 $O(n)$，信息要穿过 $n$ 次变换。**远距离依赖不再靠"记性"，而靠"直连"。**
3. **归纳偏置弱**：RNN 内置了"顺序处理"的假设，CNN 内置了"局部性"的假设。
   Transformer 几乎不预设结构，把"该看哪里"完全交给数据去学。
4. **可扩展**：结构规整（就是矩阵乘法堆叠），非常容易加宽、加深、加卡。

第 3 点是一把双刃剑。**弱归纳偏置意味着需要更多数据才能学好**——
这正好解释了为什么 Transformer 在 2017 年只是略胜，要等到 GPT-3 的数据和算力规模才真正起飞（第 7 章）。

> **跨领域对照**　这是机器学习里"**归纳偏置**"（inductive bias）的经典权衡，
> 和科学哲学里的"先验"是同一个东西：先验越强，小样本学得越快；
> 先验越弱，数据越多就越可能逼近真相。贝叶斯统计学把这件事说得最清楚：
> **先验与数据的博弈，决定了你需要的样本量。**
> Transformer 的选择是"弱先验 + 大数据"，这是一次豪赌，而且赌赢了。

## 5.10 本章小结

- **自注意力**让同一序列内的每个位置互相检索，Q/K/V 由同一个词向量线性变换而来。
- **缩放点积** $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$；除以 $\sqrt{d_k}$ 是为了防止 softmax 饱和。
- **多头**让模型同时从多个子空间看关系，分工是学出来的。
- **位置编码**补上顺序信息；正弦编码、可学习嵌入、RoPE 是三代方案。
- 一个 block = 注意力（跨位置）+ FFN（位置内）+ 残差 + 归一化；Pre-LN 更稳。
- **因果掩码**保证不看未来，同时让训练可以整句并行。
- 代价是 $O(n^2)$ 的注意力复杂度；优势是并行、短路径、弱归纳偏置、易扩展。
