# 熵：不确定性的度量 · 课程简报

> 先写清楚要解决什么问题，再开始查资料。这份简报是后面所有取舍的依据。

## 学习者

- 起点：完全没有接触过这个主题、但愿意每天花 30 分钟的人
- 已有知识：只需要会算简单概率、看得懂初中数学符号
- 学完能做到：能用自己的话解释核心机制，并判断一条新闻说得对不对

## 范围

- 必须讲：核心概念、关键机制、一个完整例子、一个常见误解
- 明确不讲：不展开实现细节与工程调参
- 目标时长：6 章，每章 30–45 分钟；视频每章 6–10 分钟
- 语言：中文

## 交付物

- [ ] 课程正文（导读 + 章节 + 附录）
- [ ] 逐句中英旁白
- [ ] 配音、字幕、背景音乐
- [ ] Remotion 视频与封面
- [ ] 来源账本与素材清单

## 验收标准

1. 每个核心概念只定义一次，且登记进概念账本。
2. 每个事实性主张都能在来源账本里找到出处。
3. 视频里的数字、公式、类比与正文一致，示意图明确标注「示意」。
4. 字幕每行中文不超过 40 字，英文不超过 110 字符。
